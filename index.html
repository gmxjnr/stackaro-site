Van commit naar website in drie stappen

  1. Je pusht je code

    Koppel je GitHub-repository. Elke push naar je hoofdbranch start een nieuwe deploy.

  2. Stackaro bouwt hem

    Je build draait in een afgesloten container, los van andere sites.

  3. Je site staat live

    De nieuwe versie gaat in één keer online. Er is geen moment dat je site half kapot is.

Wat je krijgt

Een eigen subdomein
Je site draait op jouwnaam.stackaro.nl, direct na je eerste deploy.
SSL zonder gedoe
Het slotje in de browser werkt meteen. Je regelt zelf geen certificaten.
Terugdraaien naar een eerdere versie
Stackaro bewaart je laatste versies. Gaat er iets mis, dan staat de vorige binnen een paar seconden weer online.
Voor sites die naar een map bouwen
Denk aan Vite, Astro of gewone HTML. Ondersteuning voor Next.js en andere Node-apps staat gepland.
